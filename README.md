# `accountant24-skills` plugin

The built-in skills that ship with [Accountant24](https://accountant24.ai).

## Skills

| Skill                | What it does                                                                                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `recurring-spending` | Everything you pay regularly: bills and subscriptions, monthly and yearly totals, what is due in the next 30 days, price increases, payments that stopped arriving. |
| `subscription-audit` | A cancel-focused review of subscriptions and memberships: cost per month and year, renewal dates, price increases, duplicates, forgotten charges.                   |
| `create-plugin`      | Turns a routine you describe into a plugin of your own in `~/Accountant24/plugins`.                                                                                 |

Type `/` in the message box to pick one, or just ask in your own words — the agent matches a skill by its description.
